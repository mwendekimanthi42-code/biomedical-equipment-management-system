# biomedical-equipment-management-system
A biomedical equipment management system built with Python and SQLite.
## Current Features

- Equipment registration
- Equipment viewing
- Equipment searching
- Serial number management
- Duplicate serial number prevention
- Equipment reporting
- Status and department analysis

## Technologies

- Python
- SQLite
- SQL

## Future Development

- Maintenance records
- Fault reporting
- Preventive maintenance scheduling
- User authentication
- Web interface
